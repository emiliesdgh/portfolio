Mobile Robotics

A Thymio robot that maps its environment with a camera, plans a path to the goal, and reacts to obstacles placed in its way.

  • EPFL, Lausanne
  • Course by Prof. Francesco Mondada
  • Code on GitHub
  • Python
  • OpenCV
  • Thymio
  • Path planning
  • Bayesian filtering
  • Obstacle avoidance

Overview

The robot must reach a goal through an environment with fixed obstacles, and dynamically avoid obstacles placed in its path while it moves. The project brings together computer vision, global and local navigation, motion control and Bayesian filtering in one working system.

System

Vision

OpenCV processes an overhead camera image to detect the obstacles, the robot’s pose and the target.

Global navigation

Path planning on the known map computes a collision-free route from start to goal; the target can be moved during the run.

Bayesian filtering

Fuses odometry with camera observations for robust estimation of position and orientation.

Motion control

Converts the planned path into motor commands for smooth, stable path following.

Local avoidance

The proximity sensors temporarily override the global path to get around unexpected obstacles, then the robot resumes its route.
